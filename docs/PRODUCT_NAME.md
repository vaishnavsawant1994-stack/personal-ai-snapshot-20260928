# Vishnu product name

Effective date: 2026-10-05

The product-facing name is **Vishnu** across the desktop, web/PWA, and companion experiences. Current operational documentation and UI copy use Vishnu as the product name.

Existing technical identifiers remain stable for compatibility. This includes `PERSONAL_AI_*` environment variables, Python modules and symbols such as `personal_ai_runtime` and `PersonalAICompanion`, database and vault paths, browser storage/cache keys, backup formats, app bundle/package identifiers, deployment service names, and existing URLs. These identifiers may appear in code, configuration, and old integrations, but they are not the product display name.

Dated checkpoint, qualification, and release-readiness records retain the historical name they used when that evidence was recorded. Existing installs and saved data do not need to be renamed or migrated for this product-name change.
